# Contrato de Auditoría (SDD)
**URL Objetivo:** https://demo.owasp-juice.shop/

**Instrucciones de Auditoría:**
1. Inicia navegando a la URL objetivo.
2. Si la web muestra un banner de bienvenida (con un botón "Dismiss"), ciérralo haciendo clic en él.
3. Toma una captura de pantalla de la página principal para tu evidencia.
4. Genera un reporte detallando si la tienda cargó correctamente y cuáles fueron tus hallazgos visuales.
