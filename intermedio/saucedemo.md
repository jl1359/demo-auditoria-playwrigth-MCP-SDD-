# Contrato de Auditoría Intermedio: Flujo E-commerce (QA)
**URL Objetivo:** https://www.saucedemo.com/

**Objetivo de la Auditoría:**
Realizar una prueba de Aseguramiento de Calidad (QA) verificando que el flujo de inicio de sesión y el carrito de compras funcionen correctamente.

**Instrucciones de Auditoría:**
1. Navega a la página de login de SauceDemo.
2. Llena el campo de usuario (user-name) con: `standard_user`
3. Llena el campo de contraseña (password) con: `secret_sauce`
4. Haz clic en el botón de "Login" (login-button).
5. Una vez dentro de la tienda, utiliza tus herramientas para extraer el nombre del primer producto de la lista (por ejemplo, Sauce Labs Backpack).
6. Toma una captura de pantalla para evidenciar que el inicio de sesión fue exitoso.
7. Redacta un reporte final detallando si el inicio de sesión fue exitoso, qué producto viste primero y si la página cargó sin errores visuales.
