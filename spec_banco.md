# Contrato de Auditoría: Banco de Pruebas Altoro Mutual
**URL Objetivo:** http://demo.testfire.net/

**Instrucciones de Auditoría (Flujo de Seguridad/Login):**
1. Navega al portal bancario público de pruebas de IBM (Altoro Mutual).
2. Haz clic en el botón o enlace "Sign In" (Iniciar sesión) en la esquina superior derecha o menú.
3. El sistema te llevará a la pantalla de login. Intenta ingresar con:
   - Username: `admin`
   - Password: `passwordfalso`
4. Toma una captura de pantalla del mensaje de error que arroja el sistema.
5. Analiza el mensaje de error y genera un reporte indicando si el mensaje de error expone demasiada información o si es un mensaje de error genérico seguro.
